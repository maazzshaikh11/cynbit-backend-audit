Passive backend audit of cynbit.in (Next.js on Vercel), using only anonymous GETs to public pages, robots/sitemap, one 404 probe, and public JS bundles — 33 curl requests, ≥2s apart, no forms submitted or logins attempted. Top findings: (1) no Content-Security-Policy or hardening headers on any response; (2) forms show only client-side required/email constraints, with server-side validation and rate limiting unverifiable from outside; (3) /careers and /sitemap.xml are always edge-cache MISS with the slowest TTFB. Repo includes evidence, header/bundle analysers, a prioritised roadmap, and tested snippets (security headers, validation, RFC 9457 errors, sliding-window rate limiting, caching). Reproduce with: bash scripts/passive_probe.sh, then cd snippets && npm test. Lighthouse was unavailable in this environment, so no Lighthouse scores are claimed.
